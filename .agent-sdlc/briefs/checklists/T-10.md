# T-10: keyboard cursor priority and Notes caret offset

## Brief

The shared task-page stream introduced in `ef572e3` made keyboard arrows scroll before they honor an active step cursor, while mouse-wheel events already correctly scroll only the stream. It also paints the Notes edit caret at its unscrolled row after the stream moves.

## Scope

- Keyboard arrows are cursor-first when a step cursor is active, including Up.
- Mouse wheel remains stream-only and never changes cursor state.
- Notes edit caret position accounts for the shared stream offset.
