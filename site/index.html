Human status is the source of truth.

Agents do not auto-complete your work. You move tasks with verbs. Mutating keys need Alt, so typing into a focused board cannot finish or delete anything by accident.

  1. readyon deck
  2. startedin motion
  3. blockedwaiting
  4. reviewcheck it
  5. donedrawer

Capture stays on the board.

Press + for a one-line title. Enter saves. Tab expands onto the task page for notes and scope. Tokens in the title set project and thread without leaving the line.

  • !p desk
  • !p name project by basename
  • !t name thread, normalized
  • !t unthread

Build it, then open the board.

$ git clone git@github.com:smarzban/herdr-tsk.git
$ cd herdr-tsk
$ cargo build --release
$ ./target/release/tsk

Plugin mode: herdr plugin link "$PWD", then Open tsk board. State lives in ~/.tsk either way.
